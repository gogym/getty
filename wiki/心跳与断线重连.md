# 心跳与断线重连

本页介绍 Getty 中的心跳保活和断线重连机制。

## 心跳保活

### 概述

Getty 的心跳机制由三个组件协作完成：

1. **IdleStateHandler** — 空闲状态检测，基于时间轮 O(1) 调度
2. **HeartBeatTimeOutHandler** — 心跳超时处理（用户自定义）
3. **ReConnectHandler** — 断线重连（客户端使用）

```
连接建立 → IdleStateHandler 开始计时
    ↓ 读/写空闲超时
触发 IdleState 事件
    ↓
HeartBeatTimeOutHandler 收到事件，发送心跳
    ↓ 对方无响应/连接断开
ReConnectHandler 触发重连
```

### IdleStateHandler

空闲状态检测处理器，检测通道的读写空闲状态。

```java
// 读空闲 60 秒超时，不检测写空闲
pipeline.addLast(new IdleStateHandler(60, 0));

// 读空闲 30 秒，写空闲 10 秒
pipeline.addLast(new IdleStateHandler(30, 10));

// 使用自定义时间单位
pipeline.addLast(new IdleStateHandler(5, 0, TimeUnit.MINUTES));

// 多个通道共享同一个时间轮（推荐，减少资源消耗）
HashedWheelTimer sharedTimer = new HashedWheelTimer(100, TimeUnit.MILLISECONDS);
pipeline.addLast(new IdleStateHandler(sharedTimer, 60, 0, TimeUnit.SECONDS));
```

**构造参数：**

| 参数 | 说明 |
|------|------|
| `readerIdleTime` | 读空闲超时时间，0 表示不检测 |
| `writerIdleTime` | 写空闲超时时间，0 表示不检测 |
| `unit` | 时间单位 |
| `timer` | 共享时间轮（可选，推荐多通道场景共享） |

### 处理心跳超时

在业务处理器中覆盖 `userEventTriggered` 方法处理空闲事件：

```java
public class HeartBeatHandler extends SimpleChannelInboundHandler<String> {
    
    private int idleCount = 0;
    
    @Override
    public void userEventTriggered(ChannelHandlerContext ctx, IdleState evt) throws Exception {
        if (evt == IdleState.READER_IDLE) {
            idleCount++;
            System.out.println("读空闲，第 " + idleCount + " 次");
            
            if (idleCount >= 3) {
                // 连续 3 次读空闲，关闭连接
                System.out.println("连续 3 次读空闲，关闭连接");
                ctx.channel().close();
            }
        } else if (evt == IdleState.WRITER_IDLE) {
            // 写空闲，发送心跳
            System.out.println("写空闲，发送心跳");
            ctx.channel().writeAndFlush("PING\r\n");
        }
    }
    
    @Override
    public void channelRead0(AbstractSocketChannel ch, String msg) {
        idleCount = 0;  // 收到消息，重置空闲计数
        
        if ("PING".equals(msg)) {
            // 收到心跳，回复 PONG
            ch.writeAndFlush("PONG\r\n");
        } else {
            // 正常业务消息
            System.out.println("收到: " + msg);
        }
    }
}
```

### 完整心跳管道配置

```java
server.channelInitializer(channel -> {
    ChannelPipeline pipeline = channel.getChannelPipeline();
    
    // 1. 空闲检测（读空闲 60 秒）
    pipeline.addLast(new IdleStateHandler(60, 0));
    
    // 2. 编解码器
    pipeline.addLast(new StringEncoder());
    pipeline.addLast(new DelimiterFrameDecoder(DelimiterFrameDecoder.LINE_DELIMITER));
    pipeline.addLast(new StringDecoder());
    
    // 3. 业务处理器（包含心跳处理逻辑）
    pipeline.addLast(new HeartBeatHandler());
});
```

## 断线重连

### ReConnectHandler

客户端断线重连处理器，支持 AIO 和 NIO 双模式。

```java
// 基本用法：线性递增延迟重连
pipeline.addLast(new ReConnectHandler(
    client,          // AioClientStarter 或 NioClientStarter
    1,               // 初始延迟（秒）
    10,              // 最大延迟（秒）
    1                // 延迟递增步长（秒）
));
```

**构造参数：**

| 参数 | 说明 |
|------|------|
| `client` | 客户端 Starter 实例 |
| `initialDelay` | 首次重连延迟时间 |
| `maxDelay` | 最大重连延迟时间 |
| `increment` | 每次重连后延迟递增步长 |

**重连策略：**
- 第 1 次重连：延迟 1 秒
- 第 2 次重连：延迟 2 秒（1 + 1）
- 第 3 次重连：延迟 3 秒（2 + 1）
- ...直到达到 maxDelay（10 秒）后保持不变

### 完整客户端心跳+重连配置

```java
AioClientStarter client = new AioClientStarter("127.0.0.1", 8888);
client.channelInitializer(channel -> {
    ChannelPipeline pipeline = channel.getChannelPipeline();
    
    // 1. 空闲检测（写空闲 30 秒发送心跳）
    pipeline.addLast(new IdleStateHandler(0, 30));
    
    // 2. 编解码器
    pipeline.addLast(new StringEncoder());
    pipeline.addLast(new DelimiterFrameDecoder(DelimiterFrameDecoder.LINE_DELIMITER));
    pipeline.addLast(new StringDecoder());
    
    // 3. 业务处理器
    pipeline.addLast(new SimpleChannelInboundHandler<String>() {
        @Override
        public void channelRead0(AbstractSocketChannel ch, String msg) {
            if ("PONG".equals(msg)) {
                System.out.println("收到心跳响应");
            } else {
                System.out.println("收到: " + msg);
            }
        }
        
        @Override
        public void userEventTriggered(ChannelHandlerContext ctx, IdleState evt) {
            if (evt == IdleState.WRITER_IDLE) {
                // 写空闲，发送心跳
                ctx.channel().writeAndFlush("PING\r\n");
            }
        }
    });
    
    // 4. 断线重连（加在最后）
    pipeline.addLast(new ReConnectHandler(client, 1, 10, 1));
});

client.start(new ConnectHandler() {
    @Override
    public void onCompleted(AbstractSocketChannel channel) {
        System.out.println("连接成功");
        channel.writeAndFlush("Hello\r\n");
    }

    @Override
    public void onFailed(Throwable exc) {
        System.err.println("连接失败: " + exc.getMessage());
    }
});
```

## 时间轮设计

`IdleStateHandler` 使用 `HashedWheelTimer` 替代传统的 `ScheduledExecutorService`：

- 调度与取消操作均为 O(1) 时间复杂度
- 多个 IdleStateHandler 实例可共享同一个 Timer
- 单线程即可服务成千上万个连接
- 通道关闭时自动取消定时任务，无资源泄漏

```java
// 创建共享时间轮
HashedWheelTimer sharedTimer = new HashedWheelTimer(100, TimeUnit.MILLISECONDS);

// 所有通道共享同一个 Timer
server.channelInitializer(channel -> {
    channel.getChannelPipeline()
        .addLast(new IdleStateHandler(sharedTimer, 60, 0, TimeUnit.SECONDS))
        .addLast(/* 其他处理器 */);
});
```
