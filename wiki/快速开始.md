# 快速开始

本页介绍如何快速搭建一个 Getty 服务端和客户端，实现基本的消息收发。

## 1. 引入依赖

### Maven

```xml
<!-- 核心引擎（必选） -->
<dependency>
    <groupId>com.gettyio</groupId>
    <artifactId>getty-core</artifactId>
    <version>3.0.0</version>
</dependency>

<!-- 协议编解码扩展（可选，提供字符串/HTTP/WebSocket等编解码器） -->
<dependency>
    <groupId>com.gettyio</groupId>
    <artifactId>getty-expansion</artifactId>
    <version>3.0.0</version>
</dependency>
```

### Gradle

```groovy
implementation 'com.gettyio:getty-core:3.0.0'
implementation 'com.gettyio:getty-expansion:3.0.0'
```

## 2. 启动 AIO 服务端

```java
import com.gettyio.core.channel.starter.AioServerStarter;
import com.gettyio.core.channel.AbstractSocketChannel;
import com.gettyio.core.pipeline.in.SimpleChannelInboundHandler;
import com.gettyio.expansion.handler.codec.string.*;

public class MyServer {
    public static void main(String[] args) throws Exception {
        // 创建 AIO 服务端，监听 8888 端口
        AioServerStarter server = new AioServerStarter(8888);
        
        // 配置管道
        server.channelInitializer(channel -> {
            channel.getChannelPipeline()
                // 出站：字符串编码器
                .addLast(new StringEncoder())
                // 入站：按 "\r\n" 分帧
                .addLast(new DelimiterFrameDecoder(DelimiterFrameDecoder.LINE_DELIMITER))
                // 入站：字符串解码器
                .addLast(new StringDecoder())
                // 业务处理器
                .addLast(new SimpleChannelInboundHandler<String>() {
                    @Override
                    public void channelRead0(AbstractSocketChannel ch, String msg) {
                        System.out.println("收到消息: " + msg);
                        // Echo 回复
                        ch.writeAndFlush("echo: " + msg + "\r\n");
                    }

                    @Override
                    public void channelAdded(com.gettyio.core.pipeline.ChannelHandlerContext ctx) {
                        System.out.println("新连接建立");
                    }

                    @Override
                    public void channelClosed(com.gettyio.core.pipeline.ChannelHandlerContext ctx) {
                        System.out.println("连接关闭");
                    }
                });
        });
        
        // 启动
        server.start();
        System.out.println("AIO 服务端已启动，端口: 8888");
    }
}
```

## 3. 启动 AIO 客户端

```java
import com.gettyio.core.channel.starter.AioClientStarter;
import com.gettyio.core.channel.starter.ConnectHandler;
import com.gettyio.core.channel.AbstractSocketChannel;
import com.gettyio.core.pipeline.in.SimpleChannelInboundHandler;
import com.gettyio.expansion.handler.codec.string.*;

public class MyClient {
    public static void main(String[] args) throws Exception {
        AioClientStarter client = new AioClientStarter("127.0.0.1", 8888);
        
        client.channelInitializer(channel -> {
            channel.getChannelPipeline()
                .addLast(new StringEncoder())
                .addLast(new DelimiterFrameDecoder(DelimiterFrameDecoder.LINE_DELIMITER))
                .addLast(new StringDecoder())
                .addLast(new SimpleChannelInboundHandler<String>() {
                    @Override
                    public void channelRead0(AbstractSocketChannel ch, String msg) {
                        System.out.println("收到服务端回复: " + msg);
                    }
                });
        });
        
        // 异步连接，连接成功后发送消息
        client.start(new ConnectHandler() {
            @Override
            public void onCompleted(AbstractSocketChannel channel) {
                // 连接建立成功
                channel.writeAndFlush("Hello, Getty!\r\n");
            }

            @Override
            public void onFailed(Throwable exc) {
                System.err.println("连接失败: " + exc.getMessage());
            }
        });
    }
}
```

## 4. 使用 NIO 模型

只需将 Starter 替换为 NIO 版本，其余代码完全相同：

```java
// 服务端
NioServerStarter server = new NioServerStarter(8888);
server.socketMode(SocketMode.TCP)
      .channelInitializer(channel -> { /* 同上 */ });
server.start();

// 客户端
NioClientStarter client = new NioClientStarter("127.0.0.1", 8888);
client.socketMode(SocketMode.TCP)
      .channelInitializer(channel -> { /* 同上 */ });
client.start(connectHandler);
```

## 5. 运行测试

1. 先启动服务端 `MyServer`
2. 再启动客户端 `MyClient`
3. 控制台输出：
   ```
   # 服务端
   新连接建立
   收到消息: Hello, Getty!
   
   # 客户端
   收到服务端回复: echo: Hello, Getty!
   ```
